# Mi Renta Variable

App instalable para registrar ventas, estimar la renta variable del mes y simular la liquidación.

- Los datos se guardan en una planilla de Google Sheets del usuario, mediante un Apps Script propio (el código se genera desde la app, en Ajustes → Conectar tu planilla).
- Cada dispositivo guarda una copia local; lo ingresado sin señal se sube al volver la conexión.
- Este repositorio no contiene datos de clientes ni claves.

Para instalarla: abre la página en el teléfono o el PC y elige "Agregar a pantalla de inicio" o "Instalar app".
